# Codex（ChatGPT.app）客户端设计逆向文档

> 目标：作为 dimi native-client 像素级复刻 codex 的**唯一设计依据**。
> 所有数值均为对 codex 实际渲染的观察/测量，不是猜测。
> 任何实现与本文档冲突时，以本文档为准；文档与 codex 实际不符时，先改文档再改代码。

---

## 0. 总体布局

```
┌────────────────────────────────────────────────────────────────────┐
│ Header (46px, 透明, 无边框)                                        │
├──────────────┬─────────────────────────────────────────────────────┤
│ Sidebar      │ 消息列 (736px, 居中)          │ 浮动上下文面板      │
│ 275px        │                                 │ (316px, 可开/关)  │
│              │                                 │                    │
├──────────────┴─────────────────────────────────┴────────────────────┤
│ Composer (98px, 与消息列等宽 736px, 底部 16px 边距)                  │
└────────────────────────────────────────────────────────────────────┘
```

- 窗口实测 1686×960。深色主题。
- **Sidebar 固定 275px**，可拖拽调宽（200–480），可整体隐藏（header 左侧菜单按钮切换）。
- **消息列固定 736px**，在「内容区 − 右侧浮动面板」范围内居中；右侧面板关闭时在内容区居中。
- **Composer 与消息列 1:1 对齐**：同宽（736px）、同左边缘。这是硬约束。
- 右侧浮动上下文面板 316px（`pointer-events-none absolute`，悬浮层，不占文档流），显示会话上下文/摘要。

### 颜色 token（暗色）
| token | 值 | 用途 |
|---|---|---|
| body bg | `#141414` | 页面底色 |
| surface | `#181818` | 内容区底色 |
| composer bg | `rgb(45,45,45)` + blur(16px) | 输入胶囊 |
| 文本主 | `rgba(255,255,255,0.85)` | 标题/正文 |
| 文本次级 | `rgba(255,255,255,0.55)` 附近 | 图标/次要文字 |
| 文本弱 | `rgba(255,255,255,0.35)` 附近 | 占位/提示 |
| 用户气泡 | `rgba(255,255,255,0.05)` | 右对齐气泡底 |
| hover | `rgba(255,255,255,0.08)` 附近 | 悬停底 |
| 链接 | 蓝色（chatgpt 蓝 `#0a8fff` 系） | markdown 链接 |

## 1. Header（46px）

- **整体**：`position:fixed top:0`，透明背景，无边框，高 46px。
- **左区**（宽 = sidebar 宽 275px，覆盖在 sidebar 上方）：
  - 菜单按钮（title「切换侧边栏」）：`x=0`，28×28，**columns 图标 16×16**（`icon-xs`，rotate-180），点击切换 sidebar 显隐。
  - 按钮组从 `x=88` 开始（菜单 28 + 4 gap + 56 偏移）：隐藏边栏 / 返回 / 前进，各 28×28。
- **主区**（内容区上方）：
  - 会话标题：纯文本，`14px/24px`，字重 500，左侧距 14px，`max-width:320px` 超长省略。**不是按钮、无 chevron**。
  - More 按钮（title「ChatGPT 对话操作」）：28×28，**ellipsis 18×18**（`icon-sm`），带可见边框。
- **右区**：
  - 分享 pill：`66×28`，圆角 9999，「分享」文字 + **上传图标 16×16**（`icon-xs`）。
  - 固定摘要按钮（title「切换固定摘要」）：28×28，**dots 列表图标 16×16**。
  - 最右 sidebar 切换按钮：28×28，columns rotate-180 16×16。
- **图标按钮规范**：28×28、圆角 10、透明 1px 边框（hover 时亮起）、图标默认 16×16（`icon-xs`）、ellipsis/帮助类 18×18（`icon-sm`）。

## 2. Sidebar（275px）

- 背景深色，右侧有可拖拽 resize handle（拖拽区延伸到 header，宽 16px）。
- **Brand 行**：logo/名称 + 模式 chevron，32px 高，左侧 8px 内边距。
- **导航项**（新对话 / 站点 / 已安排 / 插件）：
  - 高 30px（5px padding ×2 + 20px line-height），左右 padding 8px，圆角 12.5。
  - 图标 **16×16**（`icon-xs`）：新对话=方框铅笔、站点=双矩形、已安排=时钟、插件=拼图。
  - 文字 `rgba(255,255,255,0.85)`，hover 底 `rgba(255,255,255,0.08)` 附近。
- **分组标题**（如「最近」「k-3720」）：小字次级色，**chevron 14×14**（`icon-2xs`）。
- **会话项**：**只有标题，无左侧图标**。hover 时右侧出现操作：置顶（20×20 pin）、归档（20×20 箱）。
- **底部**（46px 高，顶部 0.5px 发丝线）：
  - 用户行：头像（18×18 圆）+ 用户名，`flex:1`，点击开个人资料菜单。
  - 帮助按钮（title「打开帮助菜单」）：32×32，**? 图标 18×18**（`icon-sm`）。

---

## 3. 消息列表（Thread / 736px 列）

- 消息列 **736px**，内容贴着列边缘（**无水平内边距**），上下 `py-5`（20px）。
- **turn（一轮对话）**：`group flex flex-col py-2`（上下 8px），turn 之间 gap 6px（`gap-1.5`）。
- **turn 内部**：`flex flex-col gap-3`（12px 间距）：
  1. 用户消息（右对齐）
  2. assistant 回复：文本（`min-w-0 text-size-chat`）+ 思考折叠区 + 工具卡片
- **用户消息**：右对齐气泡 —— `flex justify-end`，气泡底 `rgba(255,255,255,0.05)`，圆角 20，padding `8px 12px`，`max-width:77%`，14/21px。
- **assistant 文本**：左对齐纯文本，14/22px 附近（`text-size-chat`），markdown 渲染（标题/列表/表格/KaTeX 公式/引用块）。
- 连续同轮条目间距 12px；新 turn（下一条用户消息）间距 22px。

---

## 4. 思考折叠区（Reasoning Disclosure）

- **折叠按钮**：`inline-flex`，高 **21px**，文字次级色（muted），字重 ~445。
  - 文案：「思考了 X」（X = 时长，如 `2m 0s`）。
  - chevron **16×16**（`icon-xs`，`transition-transform`，展开旋转 90°）。
  - 位于消息列左边缘。
- **展开内容**：思考文本（markdown）在上，**工具卡片在下**（`margin-top:12px` 附近）。
- 工具调用**始终在折叠区内**，不独立成行、不散落在消息之间。

---

## 5. 工具调用卡片（Tool Call）

- 位于思考折叠区内部、思考文本之下。
- 卡片行：小图标 + 工具名（`font-weight:500`）+ 状态（进行中/已完成，次级色）。
- 点击展开：参数（等宽字体，前缀 `$ `）+ 输出。
- 图标用 codex 风格曲线 path（本仓库 `icons.ts` 已捕获）。

---

## 6. 悬停操作行（Hover Actions）

- 出现在用户/assistant 消息下方，`margin-top:6px`（`mt-1.5`），高 20px。
- **assistant 消息：左对齐**（`justify-start`）；用户消息：右对齐。
- 按钮：**26×26**，圆角 10，**透明 1px 边框**，透明底，hover 时亮起，gap 2。
- codex 顺序：复制 / 回复优秀 / 回复不佳 / 在新聊天中继续。dimi 至少保留「复制」。
- 默认 `opacity:0`，悬停消息时淡入。

---

## 7. Composer（98px 胶囊）

- **几何**：`736×98`（与消息列同宽同左边缘），圆角 25，背景 `rgb(45,45,45)` + blur(16px)，底部距窗口 16px。
- **结构**：上 14px 内距 → 输入行 → 底行按钮。
- **输入行**：内容距胶囊左缘 **12px**（`-mx-2` + `px-3`），最小高 44px，内容可多行滚动。
- **底行**（28px 按钮，`grid-cols-[auto auto 1fr]`）：
  - 左：添加文件（+，28×28，**plus 16×16**）。
  - 右：模型 pill（`111×28`：短模型名 + 模式 + chevron 14×14）→ 听写（mic）→ 发送（**上传箭头 16×16**，发送按钮为高对比圆形）。
- 焦点态：胶囊边框亮起（主色）。
- 忙碌/队列状态控件**浮在胶囊上方**，不占用 98px 几何。

---

## 8. 弹窗 / 菜单

- codex 本体没有 dimi 的 Session picker / Help 弹窗（那是 TUI 迁移产物）。会话切换在 sidebar 完成。
- 模态框通用：居中、圆角大（16px 级）、surface 底、深阴影。
- dimi 处理原则：**picker = 紧凑命令菜单**（440px，无标题栏，搜索框 + 列表）；approval = 权限卡（顶部主色强调条）；settings/question 用通用模态。

---

## 9. 图标系统

- 全部 `fill="currentColor"`，曲线 path（C 弧线），无手绘折线。
- 尺寸按 CSS 类，**与 svg width 属性无关**（codex 的 svg 属性写 20，实际渲染按类缩放）：
  | 类 | 渲染尺寸 | 用途 |
  |---|---|---|
  | `icon-xs` | 16×16 | header 按钮、侧栏导航、composer 按钮、思考 chevron |
  | `icon-2xs` | 14×14 | 分组 chevron、小徽标 |
  | `icon-sm` | 18×18 | header More（ellipsis）、sidebar 帮助（?） |
- 已捕获 19 个真实 path 存于 `src/renderer/icons.ts`。

---

## 10. 欢迎页 / 空状态

- codex 空会话为「今日」引导（不可控），dimi 保留自己的欢迎页（建议卡片 + 模型选择），**这是刻意保留的差异**，不强行复刻。
