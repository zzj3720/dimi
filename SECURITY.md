# Security Policy

## Supported Versions

k-3720 provides security fixes for the latest release and the current `main` branch.

## Reporting a Vulnerability

We take security seriously. **Please do not open a public issue for security vulnerabilities.**

Preferred channel:

- GitHub Security Advisories — https://github.com/zzj3720/k-3720/security/advisories/new
  (private disclosure, tracked with the codebase)

## What to Include

- Affected commit or release; include the output of `kimi --version` while the compatibility CLI keeps that command name
- Reproduction steps
- Impact assessment
- Any suggested mitigation

## Our Response

We will acknowledge your report and provide an initial assessment as soon as we can.

## Public Disclosure

We will coordinate with you on disclosure timing once a fix is ready.
